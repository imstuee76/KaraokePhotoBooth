# Changelog

All notable changes to `KaraokePhotoBooth` are tracked here.

## [1.01] - 2026-02-18
- Switched release numbering to running format (`1.01`, `1.02`, ...).
- Updated release scripts to increment running version and auto-push.

## [0.1.0] - 2026-02-18
- Initial touch-first karaoke photo booth web app.
- Added session QR gallery with expiry and per-session downloads.
- Added browser recording flow with ffmpeg transcode and thumbnail generation.
- Added config UI for timers, media quality, overlay, crop, and device preference.
